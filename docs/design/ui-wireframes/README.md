# UI Wireframes for AI SVG Maker

## Overview

This directory contains the initial UI wireframes for the **AI SVG Maker** application. The wireframes cover the core components that users will interact with:

- **Canvas** – The drawing area where the generated SVG diagram is displayed and can be edited.
- **Shape Palette** – A side‑panel that provides a set of basic shapes and AI‑generated suggestions.
- **Upload Dialog** – Modal for uploading source images or data that the AI will use to create a diagram.
- **Result View** – The final view that shows the completed SVG, download options, and sharing controls.
