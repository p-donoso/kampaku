# Eval results and run artifacts

This directory holds **operational evaluation state**, not suite specifications.

| File | Role |
|------|------|
| [`BOARD.md`](BOARD.md) | Open/resolved product gaps found while running suites |
| [`LEARNINGS.md`](LEARNINGS.md) | Deferred elevations and disposition notes from suite runs |

Suite protocols and oracles remain in the parent [`docs/eval/`](../) directory (`00-protocol.md` … `19-*.md`).

When greening a suite: update the board and learnings here; keep pass criteria in the suite file itself.
