# ADR-0000: Record significant architectural decisions

- Status: Accepted
- Date: 2026-08-28

## Context

Kampaku spans multiple repositories and security boundaries. Important choices need durable context beyond commit messages.

## Decision

Use numbered Markdown ADRs in this directory. Each ADR records status, context, decision, consequences, and superseded decisions. Proposed changes begin as `Proposed`; adopted changes become `Accepted`.

## Consequences

Cross-cutting decisions are discoverable and reviewable. Small, local implementation choices do not require ADRs.
