# Evaluation Metrics for Generated SVGs

This document defines the quantitative metrics used to evaluate the quality and performance of SVGs generated by the AI‑enhanced SVG Diagram Maker.

## Structural Similarity Index (SSIM)

**Definition:**  
SSIM measures the perceptual similarity between two images (the generated SVG rendered to a raster bitmap and a reference bitmap). It evaluates luminance, contrast, and structure, yielding a value in the range [0, 1], where 1 indicates perfect similarity.

**Measurement Method:**  
1. Render the generated SVG to a PNG bitmap at a fixed DPI (e.g., 96 dpi) and dimensions matching the reference.  
2. Compute SSIM between the generated bitmap and the reference bitmap using a standard library (e.g., `skimage.metrics.structural_similarity`).  
3. Report the mean SSIM across all color channels or the luminance channel.

**Initial Threshold:**  
SSIM ≥ 0.95

## Output File Size

**Definition:**  
The size of the generated SVG file, expressed in kilobytes (KB). Smaller file sizes indicate more efficient encoding and faster transmission.

**Measurement Method:**  
- Save the generated SVG to disk.  
- Measure the file size in bytes and convert to kilobytes (KB = bytes / 1024).  
- Record the size for each generated diagram.

**Initial Threshold:**  
File size ≤ 50 KB

## Rendering Time

**Definition:**  
The time taken to render the SVG from source to a displayable raster format (e.g., PNG) or to display it in a browser, measured in milliseconds (ms). Lower rendering time reflects better performance.

**Measurement Method:**  
- Start a high‑resolution timer before invoking the rendering engine (e.g., SVG → PNG conversion via a headless browser or library like `rsvg-convert`).  
- Stop the timer after the raster output is produced.  
- Report the elapsed time in milliseconds.  
- Optionally average over multiple runs to account for jitter.

**Initial Threshold:**  
Rendering time ≤ 200 ms
