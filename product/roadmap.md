# Initial roadmap

## Phase 0 — foundations

- establish repositories, terminology, boundaries, and contracts;
- select implementation stack through ADRs;
- define security and local-development baseline.

## Phase 1 — vertical slice

- register a Project referencing the four Kampaku repositories;
- create one Goal and one planned Task;
- register one local Worker and lease one Job;
- submit a Result and inspect its audit trail.

## Phase 2 — persistence and recovery

- durable events, retries, heartbeats, cancellation, and restart recovery;
- basic Librarian retrieval and Model Broker routing.

## Phase 3 — governed autonomy

- approvals, budgets, schedules, multi-agent planning, and multiple workers;
- web and CLI interfaces for supervision.
