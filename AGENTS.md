# Repository agent index

Before changing this repository, read [.agents/README.md](.agents/README.md) and the applicable rules in
[.agents/rules/](.agents/rules/). Repository-specific agent workflows belong under `.agents/`.

Package-local `AGENTS.md` files take precedence for their paths. In particular, `apps/web/AGENTS.md` is
managed by Next.js and must remain in place.
